# Mohammed — Cybersecurity Portfolio

Arabic-first portfolio website based on the submitted coursework archive and the provided cybersecurity study plan.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for the Pages URL to appear.

## Important
Before making the repository public, review all reports and source files. Remove passwords, API keys, private personal data, and sensitive target details. Only publish penetration-testing material you are authorized to share.
